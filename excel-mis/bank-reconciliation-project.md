# Bank Reconciliation Project

## Project Overview

This project demonstrates a practical Bank Reconciliation workflow used by accountants to compare company books with the bank statement.

The project uses fictional data for learning and portfolio purposes.

## Skills Demonstrated

* Bank Reconciliation
* Transaction Matching
* Outstanding Transaction Identification
* Bank Charges Identification
* Direct Bank Credit Identification
* Difference Analysis
* Excel Data Analysis
* Accounting Review

## Workbook Structure

The Excel workbook contains:

* Instructions
* Books Data
* Bank Data
* Reconciliation
* Summary

## Practical Accountant Workflow

**Books Data → Bank Statement → Transaction Matching → Difference Identification → Reconciliation → Review**

## Key Reconciliation Checks

* Transactions recorded in books but missing in bank
* Transactions appearing in bank but missing in books
* Bank charges
* Direct customer receipts
* Bank interest
* Amount differences
* Outstanding transactions

## Data Privacy

All data used in this project is fictional.

No confidential employer or client information should be uploaded to GitHub.
