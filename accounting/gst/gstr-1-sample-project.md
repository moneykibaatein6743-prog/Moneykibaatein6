# GSTR-1 Sample Project

## Project Objective

This project demonstrates how an accountant can review sales data before preparing GST outward-supply information.

The data used in this project is completely fictional and created for learning and portfolio purposes.

## Sample Sales Transactions

| Invoice No. | Customer | GSTIN Type | Taxable Value | GST Rate | Tax Type |

| INV-001 | ABC Traders | B2B | ₹50,000 | 18% | CGST + SGST |
| INV-002 | XYZ Pvt Ltd | B2B | ₹75,000 | 18% | IGST |
| INV-003 | Retail Customer | B2C | ₹20,000 | 18% | CGST + SGST |

## Review Points

An accountant should check:

1. Invoice number
2. Invoice date
3. Customer GSTIN
4. Customer type
5. Taxable value
6. GST rate
7. Place of supply
8. CGST/SGST/IGST
9. Credit and debit notes
10. Books vs GST data

## Reconciliation Objective

The sales register should be reconciled with the GST data before final submission.

### Key Checks

- Total taxable sales
- Total GST
- B2B sales
- B2C sales
- Export sales, if applicable
- Credit notes
- Debit notes
- Missing invoices
- Duplicate invoices
- Invoice numbering

## Important Note

This is a fictional educational dataset. It does not contain any confidential client or employer information.
